# DenGame

DenGame — личный трекер видеоигр, в котором можно собирать собственную коллекцию, планировать прохождения и сохранять игровой прогресс.

Проект создаётся как спокойный тёмный игровой архив в визуальном стиле **Plum Archive**: почти чёрный фон, сливово-фиолетовые акценты, приглушённый текст и небольшие горчичные детали.

## Статусы игр

- Хочу пройти
- Прохожу
- Пройдено
- Брошено

## Локальный запуск

Для проекта используется Node.js 24.21.0. Если установлен NVM, нужную версию можно выбрать из файла `.nvmrc`:

```bash
nvm use
```

Установить зависимости:

```bash
npm install
```

Запустить сервер разработки:

```bash
npm run dev
```

После запуска приложение будет доступно по адресу `http://localhost:5173`.

## Доступные команды

```bash
npm run dev      # Запуск сервера разработки
npm run build    # Проверка TypeScript и production-сборка
npm run lint     # Проверка ESLint
npm run preview  # Локальный просмотр production-сборки
```

## Структура исходного кода

```text

├── app/       # Инициализация приложения, маршруты и глобальные стили
├── pages/     # Страницы приложения
├── widgets/   # Крупные самостоятельные блоки страниц
├── features/  # Пользовательские действия и сценарии
```
